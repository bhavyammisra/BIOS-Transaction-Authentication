# Pitch & demo

## Demo script (draft)
1. Legit purchase from a known device → **allow** in ~20 ms
2. Same user, new device, 8× normal amount → **challenge** (OTP), with reasons shown
3. Bot-speed checkout from an emulator over VPN, after failed logins → **block**
4. Dashboard: live feed, reasons panel, latency chart

## Deck outline
Problem → Why it's hard (friction vs fraud) → Our approach → Live demo → Architecture → Results/metrics → Next steps

- Where would real data come from? Privacy?
